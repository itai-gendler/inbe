# Appearance settings

Selected appearance preferences.

## Information kept

- **Theme** — Selected shipped theme or custom appearance.
- **Source selection** — Whether appearance follows the selected app theme or the system palette.
- **Mode** — Preferred light, dark or system appearance mode.
- **Scale** — Saved interface scale preference.
