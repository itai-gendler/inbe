# Friend request

Cached incoming or outgoing request information.

## Information kept

- **Identity** — Cached request identity distinguishing an incoming or outgoing request.
- **Direction** — Whether the cached request is incoming or outgoing.
- **Display identity** — Available public identifier or alias displayed for the requested relationship.
