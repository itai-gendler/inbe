# Wim Hof settings

Wim Hof breathing configuration.

## Information kept

- **Rounds** — Configured number of breathing and retention rounds.
- **Breaths** — Configured breaths within each round.
- **Speed** — Configured breath progression speed.
- **Progression** — Saved automatic or supported manual progression preference.
- **Start preference** — Saved preference controlling the start of the Wim Hof process.
- **Between-round pause** — Configured pause between successive rounds.
- **Animation** — Saved preference for the practice animation.
